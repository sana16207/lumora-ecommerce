# Lumora E-Commerce Platform

A full-stack modern e-commerce platform built using React, TypeScript, Spring Boot, MySQL, JWT Authentication, Razorpay Payments, and Admin Analytics Dashboard.

## Features

### Customer Features

- User Registration & Login
- JWT Authentication
- Browse Products
- Product Details Page
- Wishlist
- Shopping Cart
- Checkout
- Razorpay Payment Gateway
- Cash On Delivery (COD)
- Order Placement
- Order Tracking
- Cancel Orders
- Reorder Products
- Saved Address Support

### Admin Features

- Admin Dashboard
- Product Management (CRUD)
- Order Management
- User Management
- Block / Unblock Users
- Order Status Updates

Order Flow:

PLACED
→ PROCESSING
→ SHIPPED
→ DELIVERED

### Analytics

- Total Products
- Total Orders
- Total Users
- Revenue Dashboard
- Order Status Analytics
- Monthly Sales Trend
- Low Stock Alerts
